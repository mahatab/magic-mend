## Decision (reviewed)

The automatic summary that the harness writes chose haiku by counting checks alone. Reading every output changes the pick.

**Warm mode: go.** A warm spare cuts the wait for first words on both models: haiku from 3551 ms to 2761 ms (1010 ms with priming), sonnet from 1627 ms to 1195 ms.

**Model: sonnet (default), haiku available in Settings.**

- Sonnet is faster once warm: first words 1195 ms median against 2761 ms, and finished drafts 1647 ms against 3101 ms. Only primed haiku comes close (1321 ms total), and that costs a priming request for every spare.
- Sonnet does Fix errors only properly. For "i has send the payment yesterday", haiku returned "I have sent the payment yesterday" (still wrong) and sonnet returned "I sent the payment yesterday".
- Haiku left sentence starts in lower case in several drafts ("hi chi, we had a great stay"); sonnet capitalized them.
- Haiku changed one date format ("Dec 22" to "December 22"). The spec asks for dates exactly as written.

**Priming: off.** It helps haiku but not sonnet (1421 ms primed against 1195 ms warm), so it would only add a request per spare.

**Output rules (acceptance test 8).** 90 of 90 runs passed the contraction and em dash check without needing the fix round.

**Facts (acceptance test 9).** Every flagged run was read by hand. Most flags were wording, not facts: "Thursday 2pm" became "Thursday at 2pm" and "twice" became "two times". Names, numbers, times, links, addresses, and order numbers were all kept. The one real slip was haiku writing "December 22" for "Dec 22", one more reason for sonnet.

**Speed target.** With sonnet warm, first words arrive in about 1.2 s and the finished drafts in about 1.6 s, well inside the 4 second target. The popup itself appears 109 ms after the hotkey (measured in the end-to-end test).

**Isolation (acceptance test 18).** `mm-harness isolation` added a marker line to the user CLAUDE.md and a logging hook to user settings. The engine reply had no marker and the hook never ran. A control run without the isolation flags showed the marker and ran the hook 11 times. Both files were restored byte for byte.

**Follow-ups (acceptance test 10).** `mm-harness quality`: after "remove the apology", both drafts dropped "sorry for the delay" and kept "Omar", "Tuesday 3pm", and "$480" unchanged.
